# 🛒 Next.js SSR E-Commerce Application

A responsive and SEO-friendly E-Commerce application built using **Next.js** with **Server-Side Rendering (SSR)**. The project was developed as a technical assessment and consumes product data from external APIs provided by the company.

## 🚀 Features

* Server-Side Rendering (SSR)
* Product Listing Page
* Product Details Page
* Shopping Cart Functionality
* Redux Toolkit State Management
* Dynamic Routing
* Responsive Design
* Search and Filtering
* Loading and Error States
* Dynamic Imports for Performance Optimization
* SEO-Friendly Architecture

## 🛠 Tech Stack

* Next.js
* React.js
* Redux Toolkit
* JavaScript (ES6+)
* Tailwind CSS
* Bootstrap

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>

```

### Install Dependencies

```bash

```

### Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
